# 前台配色中心

v3.0.0 新增的配色入口位于首页“延迟监测中心”和后台齿轮之间。它不依赖管理权限，不受隐藏延迟入口的设置控制。

## 预览与恢复

- 保留翡翠、柔和、高对比、午夜、自定义；“原版柔雾”是新增选项，不会自动覆盖原站点配色。
- 浅色／北京时间自动／深色仍是三个页面模式。“编辑浅色／编辑深色”只选择编辑的五个字段，不改页面模式。
- 色盘、RGB、六位 HEX 保留当前透明度；八位 HEX 明确指定透明度。透明度内部保存为 0–255 字节，不因显示百分比而反复舍入。
- 不完整或非法输入保留原文和最后有效预览，阻止套用；取消／Escape 放弃草稿。“恢复本色组”只改五项，“恢复全部柔雾预设”从不可变默认值复制十项，均须再点击套用或保存。
- 高级 JSON 必须包含十个合法 HEX；六位 JSON 色视为不透明。未知键会提示并忽略，导出不含站点设置、账号或会话。
- 编辑器与入口使用独立安全底色，即使监控页面被调成白字白底，仍可取消或重设。

## 本机与全站

“套用到此浏览器”只保存同源、同部署路径下的版本化本机偏好；浏览器禁止存储时只应用当前页面并提示。“跟随站点配色”只清除该本机键，不删除其他存储。

“验证权限并编辑全站配色”会重新检查登录和管理权限，再读取当前站点配色；不会把个人覆盖默认当成服务器原值。复制个人配色是独立动作。确认保存后，以最新完整设置为底只修改 `glassColorPreset` 和 `glassCustomColors`，后者采用后台 richtext 可读取的十键 JSON 字符串。

配色与 Ping 配置写入共用有界串行队列。配色被其他操作更改时停止提交；网络、权限、主题变化及读回不一致均不会显示成功。请求可能已提交但无法读回时显示“保存结果待确认”，请重新读取核对，不要重复提交。关闭面板不能撤销已经到达服务器的请求。

同页队列不等于跨用户事务或服务器 CAS；多人同时改设置仍应协调。保存全站后如本机覆盖仍在，会明确提示，并不会偷偷删除本机偏好。后台原配色与色觉辅助字段保持可用。

注意官方旧后台主题表单与 Plus 前台保存不同：1.5.1／fix1／1.5.0／1.4.3 的表单会移除 manifest 未声明的未知扩展字段；1.6.0 已验证保留。普通已声明字段和配色往返正常，详见[兼容记录](compatibility/komari-1.6.0.md)。

## 范围

配色预览不新增监控请求、不改变 Ping 统计或任务选择。减少透明度／不支持模糊时使用更实的表面；不减少信息。旧 `/sw.js` 在线兼容合同不变，见[启动兼容说明](compatibility/service-worker.md)。预发布仍需实际设备试用，不构成任意自定义配色的对比度保证。
