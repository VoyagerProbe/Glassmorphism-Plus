# 前台配色中心

v3.0.0 新增的配色入口位于首页“延迟监测中心”和后台齿轮之间。它不依赖管理权限，不受隐藏延迟入口的设置控制。

## 预览与保存

- 保留翡翠、柔和、高对比、午夜、自定义；原有方案的外观以 v2.8.4 为基准。
- 浅色／北京时间自动／深色仍是三个页面模式。“编辑浅色／编辑深色”只选择编辑的五个字段，不改页面模式。
- 色盘、RGB、六位 HEX 保留当前透明度；八位 HEX 明确指定透明度。透明度内部保存为 0–255 字节，不因显示百分比而反复舍入。
- 不完整或非法输入保留原文和最后有效预览，阻止保存；合法输入或重新选择方案可退出错误状态。取消／关闭／Escape 放弃草稿，不回退独立操作的页面主题模式。
- 高级 JSON 必须包含十个合法 HEX；六位 JSON 色视为不透明。未知键会提示并忽略，导出不含站点设置、账号或会话。
- 编辑器与入口使用独立安全中性色，即使监控页面被调成白字白底，仍可编辑或取消。

## 本机与全站

每次打开默认编辑个人配色；访客不显示范围切换，底部仅有“取消／保存”。保存只对同源、同部署路径下的当前浏览器生效；浏览器禁止存储时只应用当前页面并明确提示未永久保存。

个人方案中的“站点默认”是跟随意图，不是后台 preset：选择时只预览，取消保留原个人配色，保存才删除本主题配色覆盖键。后续站点改色可继续跟随；手工编辑则从当前完整十色转成自定义草稿，不写服务器。

存在管理会话时显示紧凑的“修改范围”选择。选择“全站默认”会重新检查真实管理权限并读取站点配色；已登录不等于已验证管理员。范围切换有未保存草稿时先确认。全站模式不显示自引用的“站点默认”方案，底部仅有“取消／保存全站”，保存时进行一次确认。

全站保存以最新完整设置为底，只修改 `glassColorPreset` 和 `glassCustomColors`，后者采用后台 richtext 可读取的十键 JSON 字符串。不会把个人覆盖自动带入全站，也不会自动清除个人覆盖；成功后仍有个人覆盖时会明确提示。后台原配色与色觉辅助字段保持可用。

配色与 Ping 配置写入共用有界串行队列。配色被其他操作更改时停止提交；网络、权限、主题变化及读回不一致均不会显示成功。请求可能已提交但无法读回时显示“保存结果待确认”，请重新读取核对，不要重复提交。关闭面板不能撤销已经到达服务器的请求。

同页队列不等于跨用户事务或服务器 CAS；多人同时改设置仍应协调。低频 JSON 与重新读取操作放在折叠的高级区域；没有常驻恢复按钮。

注意官方旧后台主题表单与 Plus 前台保存不同：1.5.1／fix1／1.5.0／1.4.3 的表单会移除 manifest 未声明的未知扩展字段；1.6.0 已验证保留。普通已声明字段和配色往返正常，详见[兼容记录](compatibility/komari-1.6.0.md)。

## 旧候选设置兼容

仅明确的 `softFrost`／柔雾标识已退役，不再可选或新写出。本机旧记录不作为有效覆盖，但原始内容保留到用户明确保存；保存“站点默认”只删除配色覆盖键。后台旧值按原默认翡翠读取，访客启动不写服务器；管理员下次明确保存才输出支持的方案，原自定义 JSON 与其他设置不自动清空。真正 `custom` 配色即使十色与旧方案相同也完整保留，不按颜色相似度迁移。

## 范围

原有外观通过实际 v2.8.4 安装包与修订构建的同条件对照：合成数据、时间、字体、viewport、深浅模式及方案一致，配色面板关闭且没有个人覆盖。16 组检查覆盖四个原方案、四档卡片、列表、详情与 Ping 弹窗，比较几何、材质、主次文字、阴影、hover 和图表样式；新增配色入口保留，不把它误当成旧界面的回归。

配色预览不新增监控请求、不改变 Ping 统计或任务选择。原方案维持旧材质；自定义颜色保留严格解析、主次文字响应及 hover 不降低透明度的安全修正。旧 `/sw.js` 在线兼容合同不变，见[启动兼容说明](compatibility/service-worker.md)。预发布仍需实际设备试用，不构成任意自定义配色的对比度保证。
