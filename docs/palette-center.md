# 前台配色中心

v3.0.0 的配色入口位于首页“延迟监测中心”和后台齿轮之间，对所有访客可见且可打开。它不受隐藏延迟入口的设置控制；后台按钮继续遵守自己的可见性规则。

## 公开只读查看

未登录、普通登录但无管理权限或权限验证失败时，面板只展示现有公开主题设置规范化后的方案与浅深十色。没有编辑输入、导入、草稿预览或保存；查看与关闭不请求管理员接口，不建立个人配色覆盖，不展示完整设置或管理资料。

入口可见性与编辑／保存权限分离。管理会话退出、过期或变更会关闭旧编辑器并撤销未提交草稿，入口仍在，可以重新以只读方式打开。现有认证同步取得新管理员会话且验证通过后，无需刷新即可再次打开编辑器。

## 预览与保存

- 保留翡翠、柔和、高对比、午夜、自定义；原有方案的外观以 v2.8.4 为基准。
- 浅色／北京时间自动／深色仍是三个页面模式。“编辑浅色／编辑深色”只选择编辑的五个字段，不改页面模式。
- 卡片、控制区、主文字、次文字、边框为一组紧凑色点按钮；色点显示当前草稿色组的真实值，支持键盘方向键、Home／End 与 Enter／Space。窄屏自然换行，切换不保存。
- 色盘、RGB、六位 HEX 保留当前透明度；八位 HEX 明确指定透明度。透明度内部保存为 0–255 字节，不因显示百分比而反复舍入。
- 不完整或非法输入保留原文和最后有效预览，阻止保存；合法输入或重新选择方案可退出错误状态。取消／关闭／Escape 放弃草稿，不回退独立操作的页面主题模式。
- 高级 JSON 必须包含十个合法 HEX；六位 JSON 色视为不透明。点击“导入”只原子更新草稿与预览，点击“保存”才应用到全站。未知键会提示并忽略，导出不含站点设置、账号或会话。
- 编辑器与入口使用独立安全中性色，即使监控页面被调成白字白底，仍可编辑或取消。

## 统一全站配色

管理员编辑模式只编辑站点默认，不再提供个人配色、修改范围或“站点默认”自引用选项。编辑底部仅有“取消／保存”，只读模式仅提供关闭。管理员保存并读回核验成功后显示“全站配色已保存。”，从提示出现起 5 秒自动关闭，仍可手动关闭；错误与待确认消息不套用该计时。其他浏览器通过正常读取设置、刷新或重新打开取得新配色，不强制刷新、广播或新增轮询。

有效配色顺序为：已授权编辑中的草稿 → 当前站点设置 → 安全默认。旧个人配色专用键 `glassmorphism-plus:palette:v1:<部署路径编码>`（旧 schemaVersion 1）原文保留但完全忽略，包括损坏、未知 schema、custom 与旧预设；不监听这些键的 storage 事件、不迁移到服务器。themeMode、收藏及其他本机偏好不变。

已登录不等于管理员：编辑资格复用固定的后台权限检查，每次已登录会话变化最多一次，不新增权限轮询；只读面板不会触发该检查。已获资格的会话打开编辑器时再次验证会话、管理权限及当前主题，并读取最新完整设置；加载未完成或失败时不可编辑／保存，仍可关闭。草稿与基线独立复制；取消、关闭、Escape 或离开页面后显示当下站点配色，不恢复打开时的旧快照。会话变化撤销预览，迟到的请求不得恢复旧草稿。

点击保存直接进入受控流程，不再弹出重复确认；保存期间禁止重复提交及编辑。以最新完整设置为底，只修改 `glassColorPreset` 和 `glassCustomColors`，后者采用后台 richtext 可读取的十键 JSON 字符串。未修改草稿不能空写；旧个人记录不会进入保存链。后台原配色与色觉辅助字段保持可用。

配色与 Ping 配置写入共用有界串行队列。配色被其他操作更改时停止提交；网络、权限、主题变化及读回不一致均不会显示成功。请求可能已提交但无法读回时显示“保存结果待确认”，请关闭并重新打开配色中心核对，不要重复提交。关闭面板不能撤销已经到达服务器的请求。

同页队列不等于跨用户事务或服务器 CAS；多人同时改设置仍应协调。折叠的高级区域保留 JSON 导入与复制，不再提供手动重新读取按钮；开窗加载、保存前 fresh read、冲突检查与保存后读回均保留。

注意官方旧后台主题表单与 Plus 前台保存不同：1.5.1／fix1／1.5.0／1.4.3 的表单会移除 manifest 未声明的未知扩展字段；1.6.0 已验证保留。普通已声明字段和配色往返正常，详见[兼容记录](compatibility/komari-1.6.0.md)。

## 旧候选设置兼容

后台明确的 `softFrost`／柔雾标识只读回退到原默认翡翠，不再可选或新写出；访客启动不写服务器，管理员明确修改并保存才输出支持的方案。真正的站点 `custom` 即使十色与旧方案相同也完整保留，不按颜色相似度迁移。所有旧个人配色记录均保持原文，但不再参与外观。

## 范围

原有外观通过实际 v2.8.4 安装包与修订构建的同条件对照：合成数据、时间、字体、viewport、深浅模式及方案一致，配色面板关闭且没有个人覆盖。16 组检查覆盖四个原方案、四档卡片、列表、详情与 Ping 弹窗，比较几何、材质、主次文字、阴影、hover 和图表样式；新增配色入口保留，不把它误当成旧界面的回归。

配色预览不新增监控请求、不改变 Ping 统计或任务选择。原方案维持旧材质；自定义颜色保留严格解析、主次文字响应及 hover 不降低透明度的安全修正。旧 `/sw.js` 在线兼容合同不变，见[启动兼容说明](compatibility/service-worker.md)。预发布仍需实际设备试用，不构成任意自定义配色的对比度保证。
